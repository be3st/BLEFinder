BLUETOOTH FINDER 1.2 - WINDOWS / ANDROID STUDIO

SO AKTUALISIERST DU DIE APP:
1. Dieses ZIP entpacken.
2. In Android Studio den entpackten Ordner BLEFinder oeffnen.
3. Gradle Sync abwarten.
4. Handy per USB anschliessen und USB-Debugging erlauben.
5. Oben das Handy auswaehlen.
6. Run 'app' starten.

Die vorhandene Version 1.1 kann dadurch direkt aktualisiert werden.

HANDY-zu-HANDY-TEST:
Ziel-Handy:
- App 1.2 oeffnen.
- "Finder-Signal von diesem Handy senden" antippen.

Such-Handy:
- "Suche starten" antippen.
- In der Liste "BLE Finder-Handy" auswaehlen.
- Je staerker/gruener der RSSI-Wert, desto naeher ist das Signal typischerweise.

WICHTIG:
Bluetooth EIN bedeutet bei Handys nicht automatisch "sichtbar". Android-Handys sind normalerweise nicht dauerhaft auffindbar. Fuer ein beliebiges Handy muss dieses entweder BLE senden oder Classic-sichtbar gemacht werden. Die App bietet dafuer auf dem Ziel-Handy beide Optionen.
